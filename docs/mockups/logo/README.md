# Yapa — logo: 3 variantes

Paleta: `#D95D39` · `#B5492A` · `#8C3524` · `#E0A458` · tinta `#2B1B12`.
Serif de sistema (Georgia); fondo transparente; modo oscuro vía `prefers-color-scheme`.

## logo-wordmark.svg
**El punto es la yapa.** "Yapa" en serif editorial itálica; el punto final se vuelve un solcito ocre con rayos terracota: el extra que cierra el nombre.

## logo-mark.svg
**La Quebrada + la que sobra.** Tres cerros escalonados en tonos tierra, esquinas redondeadas, y un sol-punto flotando arriba a la derecha. Silueta simple, legible a 32px.

## logo-lockup.svg
**Marca completa para header.** Cluster de cerros a la izquierda + wordmark con solcito, baseline alineado; pensado para navbar en claro u oscuro.
